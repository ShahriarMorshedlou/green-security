
# Green Security — سامانه تحلیل هشدارهای امنیتی

[English](README.md) | [فارسی](README.fa.md)

## معرفی پروژه

این پروژه با زبان Python توسعه داده شده و هدف آن تحلیل و پردازش هشدارهای امنیتی ذخیره‌شده در فایل JSON است.

برنامه اطلاعات مربوط به هر هشدار را استخراج می‌کند، آن‌ها را بر اساس سطح اهمیت دسته‌بندی می‌کند و گزارش‌هایی از وضعیت هشدارها ارائه می‌دهد.

این پروژه با هدف تمرین مفاهیم برنامه‌نویسی Python و آشنایی عملی با پردازش داده‌های امنیتی طراحی شده است.

## قابلیت‌ها

- خواندن اطلاعات از فایل JSON
- استخراج اطلاعات مربوط به هشدارهای امنیتی
- بررسی و اعتبارسنجی داده‌های ورودی
- دسته‌بندی هشدارها بر اساس سطح اهمیت
- محاسبه آمار مربوط به هشدارها
- محاسبه بیشترین و میانگین امتیاز ریسک
- شناسایی هشدارهای با ریسک بالا
- جست‌وجو بر اساس آدرس IP مبدأ
- جست‌وجو بر اساس نام هشدار
- فیلتر کردن هشدارها بر اساس سطح اهمیت
- استخراج و نمایش اطلاعات شواهد امنیتی
- شناسایی هشدارهای تکراری بر اساس شناسه Rule
- تولید گزارش نهایی در قالب JSON

## ساختار داده‌های ورودی

اطلاعات هر هشدار امنیتی شامل چند بخش اصلی است:

### Rule

این بخش اطلاعات مربوط به قانون شناسایی هشدار را نگهداری می‌کند.

اطلاعات مهم آن عبارت‌اند از:

- `id`: شناسه قانون
- `name`: نام هشدار
- `severity`: سطح اهمیت
- `risk_score`: امتیاز ریسک
- `logic`: منطق شناسایی هشدار

### Event

این بخش اطلاعات رویدادی را که باعث ایجاد هشدار شده است، نگهداری می‌کند.

برخی از اطلاعات آن عبارت‌اند از:

- `@timestamp`: زمان وقوع رویداد
- `source.ip`: آدرس IP مبدأ
- `destination.ip`: آدرس IP مقصد
- `http.request.method`: متد درخواست HTTP
- `url.path`: مسیر درخواست
- `http.response.status_code`: کد وضعیت پاسخ HTTP
- `event.outcome`: نتیجه رویداد

### Evidence

این بخش شواهدی را که در شناسایی هشدار نقش داشته‌اند، نگهداری می‌کند.

اطلاعات آن شامل موارد زیر است:

- `reason`: دلیل شناسایی هشدار
- `confidence`: میزان اطمینان
- `matched_pattern`: الگوی شناسایی‌شده

## تحلیل و گزارش‌گیری

برنامه اطلاعات هشدارها را بررسی می‌کند و آمار مختلفی از آن‌ها ارائه می‌دهد.

مهم‌ترین موارد تحلیل عبارت‌اند از:

- تعداد کل هشدارها
- تعداد هشدارها در هر سطح اهمیت
- بیشترین امتیاز ریسک
- میانگین امتیاز ریسک معتبر
- نمایش هشدارهای با سطح اهمیت بالا و بحرانی
- بررسی هشدارهای تکراری
- جست‌وجو و فیلتر کردن اطلاعات

سطوح اهمیت هشدارها عبارت‌اند از:

- `Critical`
- `High`
- `Medium`
- `Low`
