
# Green Security — تحلیل‌گر هشدارهای امنیتی

[English](README.md) | [فارسی](README.fa.md)

## معرفی پروژه

Green Security یک برنامه مبتنی بر Python است که با هدف پردازش، تحلیل و تهیه گزارش از هشدارهای امنیتی ذخیره‌شده در یک فایل JSON توسعه داده شده است.

این برنامه اطلاعات مهم هر هشدار را استخراج می‌کند، هشدارها را بر اساس سطح شدت دسته‌بندی می‌کند، آمارهای مختلف را محاسبه می‌کند، امکان جست‌وجو و فیلتر کردن هشدارها را فراهم می‌کند و در نهایت یک گزارش ساختاریافته با فرمت JSON تولید می‌کند.

تمرکز این پروژه بر تحلیل اولیه هشدارهای امنیتی و پردازش داده‌ها است و از مدل‌های هوش مصنوعی یا یادگیری ماشین استفاده نمی‌کند.

## قابلیت‌ها

- **پردازش داده‌های JSON:** خواندن و پردازش هشدارهای امنیتی از فایل JSON.
- **استخراج اطلاعات هشدارها:** استخراج اطلاعات مهم مانند شناسه قانون، نام هشدار، سطح شدت، امتیاز ریسک، زمان ثبت و آدرس‌های IP.
- **تحلیل سطح شدت:** دسته‌بندی هشدارها در چهار سطح Critical، High، Medium و Low.
- **تحلیل آماری:** محاسبه آمار هشدارها، میانگین Risk Score و شناسایی هشدار با بالاترین امتیاز ریسک.
- **شناسایی هشدارهای پرریسک:** شناسایی هشدارهایی که امتیاز ریسک بالایی دارند.
- **جست‌وجوی هشدارها:** جست‌وجو بر اساس Source IP، نام هشدار و سطح شدت.
- **تحلیل شواهد:** استخراج دلیل ثبت هشدار، سطح اطمینان، نتیجه رویداد و الگوی شناسایی‌شده.
- **اعتبارسنجی داده‌ها:** مدیریت فیلدهای ناقص، خالی یا نامعتبر در هشدارها.
- **تولید گزارش JSON:** ایجاد یک گزارش ساختاریافته شامل اطلاعات پردازش‌شده هشدارها.
- **شناسایی هشدارهای تکراری:** شناسایی هشدارهایی که دارای Rule ID تکراری هستند.

## داده‌های ورودی

فایل `security_alerts.json` به‌عنوان مجموعه داده ورودی برنامه استفاده می‌شود.

هر هشدار امنیتی شامل سه بخش اصلی است:

### Rule

- `id`: شناسه منحصربه‌فرد قانون شناسایی.
- `name`: نام یا نوع فعالیت مشکوک.
- `severity`: سطح شدت هشدار.
- `risk_score`: امتیاز ریسک اختصاص‌یافته به هشدار.
- `logic`: منطق مورد استفاده برای شناسایی فعالیت مشکوک.

### Event

- `@timestamp`: زمان ثبت رویداد.
- `source.ip`: آدرس IP مبدأ.
- `destination.ip`: آدرس IP مقصد.
- `http.request.method`: متد درخواست HTTP.
- `url.path`: مسیر درخواست‌شده.
- `http.response.status_code`: کد وضعیت پاسخ HTTP.
- `event.outcome`: نتیجه ثبت‌شده رویداد.

### Evidence

- `reason`: دلیل ایجاد هشدار.
- `confidence`: سطح اطمینان فرایند شناسایی.
- `matched_pattern`: الگوی مشکوک شناسایی‌شده.

برخی از فیلدها ممکن است وجود نداشته باشند یا مقدار خالی داشته باشند. برنامه هنگام پردازش، داده‌های ناقص را مدیریت می‌کند.

## تحلیل و گزارش‌گیری

برنامه عملیات تحلیلی مختلفی را روی هشدارهای امنیتی انجام می‌دهد:

- دسته‌بندی هشدارها بر اساس سطح شدت: Critical، High، Medium و Low.
- محاسبه تعداد کل هشدارها.
- محاسبه میانگین Risk Scoreهای معتبر.
- شناسایی هشدار دارای بالاترین Risk Score.
- استخراج هشدارهای دارای سطح شدت High و Critical.
- جست‌وجوی هشدارها بر اساس معیارهای مختلف.
- شناسایی هشدارهای تکراری بر اساس `rule.id`.
- استخراج شواهد موجود برای هر هشدار.

برنامه اطلاعات و شواهد ثبت‌شده را گزارش می‌کند، بدون اینکه فرض کند حمله شناسایی‌شده الزاماً با موفقیت انجام شده است.

- هشدارهای High و Critical.

خروجی برنامه با فرمت معتبر JSON ذخیره می‌شود.
